## 4. Hiệu chỉnh thiết kế §10: query eval = ảnh + attribute (ZSL)

### 4.1. Yêu cầu user

- “Ở đề xuất 2 thì phần input query chính vẫn phải là **ảnh + attribute** theo đúng zeroshot task, **không** dùng hẳn LLM text before.”

### 4.2. Quyết định chốt (quan trọng)

| Chốt | Bác bỏ / không dùng |
| --- | --- |
| Query eval chính: $\hat{v}_x=\mathrm{Normalize}(\phi_{\mathrm{img}}(x))$ + $\hat{e}^{a}_c=\mathrm{Normalize}(W_a a_c)$ | Before-LLM free-text / LLM text làm **query** |
| Q1: $q(x)=\hat{v}_x$; Q2 (khuyến nghị): $q(x,c)=\mathrm{Normalize}(\lambda_q\hat{v}_x+(1-\lambda_q)\hat{e}^{a}_c)$ | $q=\phi_{\mathrm{txt}}(\mathrm{LLM\ text})$ |
| Bank $B_1$–$B_4$ chỉ là **memory offline** (after-LLM items) | Thay attribute protocol ZSL bằng text LLM làm input task |
| Fuse $p^{\mathrm{fuse}}=\mathrm{Normalize}(\beta W_s h + (1-\beta) W_a a_c)$ rồi IPR + matching | |

**Lý do:** đúng protocol ZSL (ảnh + side-info attribute); LLM text unseen offline OK như semantic memory, không phải query; tránh mismatch “eval bằng before-LLM text” không khớp task chuẩn.
