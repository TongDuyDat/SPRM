4.1. Overview
This study proposes a new framework called
Hierarchical Semantic Prototype Refine-
ment Network (HSPRN)for Zero-Shot Learn-
ing (ZSL). The main idea is to construct rich se-
mantic prototypes for each class and then refine
these prototypes using image-specific visual fea-
tures. The proposed framework aims to reduce the
semantic–visual gap and improve the recognition
ability for unseen classes.
In Zero-Shot Learning, the training set only con-
tains samples from seen classes:
Y s,(1)
while the testing stage contains unseen classes:
Y u,(2)
with:
Y s ∩ Y u =∅.(3)
The objective is to recognize unseen classes with-
out using any training images from these classes.
The proposed HSPRN framework consists of five
main modules:
•Primitive Semantic Constructor;

4.8. Training Objective
The proposed framework is trained using only
samples from seen classes. Given a training sample
(x, y), wherexis an image andy∈ Y s is its ground-
truth label, the objective function is designed to op-
timize semantic consistency, visual–semantic align-
ment, prototype refinement, and classification per-
formance simultaneously.
Unlike contrastive learning methods for natural
image retrieval, the proposed framework does not
rely on large-scale Top-K hard negative mining.
This is because the ZSL setting already operates
on a limited number of semantic classes with prede-
fined semantic relationships. Instead, the proposed
method focuses on preserving semantic structure
and improving prototype discrimination through
semantic alignment and prototype refinement.
The overall training objective consists of four loss
components:
L=λ 1Lcls +λ 2Lsem +λ 3Lalign +λ 4Lpres,(30)
where:
•L cls is the classification loss;
•L sem is the semantic consistency loss;
•L align is the visual–semantic alignment loss;
•L pres is the prototype preservation loss;
•λ 1, λ2, λ3, λ4 are balancing coefficients.

4.8.5. Overall Optimization
The final training objective combines all loss
terms:
L=λ 1Lcls +λ 2Lsem +λ 3Lalign +λ 4Lpres.(36)
The optimization process jointly updates:
•the semantic projection module;
•the visual encoder;
•the feature aggregation module;
•the prototype refinement module.
Through this joint optimization strategy, the
proposed framework learns semantically meaning-
ful and visually adaptive prototypes, which im-
proves knowledge transfer from seen classes to un-
seen classes.
